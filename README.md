# ImLisan - Language Learning Platform

ImLisan is a smart language learning platform that helps you build real-world fluency through interactive lessons, real-time practice, and personalized paths.

## Features
- Interactive bite-sized language lessons
- Real-time vocabulary & grammar practice
- Personalized learning paths

## Tech Stack
- **Framework:** Next.js
- **Deployment:** Vercel
